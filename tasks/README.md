# tasks/

This folder holds the work files for the current round of building Rotland.

- `LEAD.md` holds the master rules for every lead round. Read it first.
- The round's own files (round plan, prompt, and task files) go here while the round is active.
- Finished rounds are moved to `tasks/archive/`, so this folder stays short.
- Old files in `tasks/archive/` are kept for history only. Do not edit them.
