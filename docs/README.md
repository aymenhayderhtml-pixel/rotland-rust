# Rotland docs index

Short guide to the project notes in this folder. Start with `STATUS.md`.

- `STATUS.md`: where the project is now, what was just done, and what is next.
- `DECISIONS.md`: the choices the owner has locked in, with dates.
- `GAME_DESIGN.md`: the game idea, rules and open questions.
- `PLAN_0.2.md`: the plan for version 0.2 and how the AI helpers work.
- `PLAN_0.2_PUSH.md`: the day-by-day plan for the 0.2 push (2026-11-22 to 11-27).
- `PARITY_OPEN.md`: the few features from the old Godot version that are still missing.
- `ISSUES.md`: problems the owner reported while playing (pictures in `issues/`).
- `JESTER.md`: log of mistakes made by AI helpers, and what was learned.
- `AI_WORKFLOW.md`: the older rules for how AI helpers write and check code.
- `CODEMAP.md`: map of the code folders, crates and data files.
- `WORLD.md`: the world layout, biomes and danger zones.
- `ART_PIPELINE.md`: how 3D models are made and baked (style and palette rules).
- `RIG_CONTRACT.md`: rules for the human-shaped characters (skeleton and bones).
- `ANIMAL_CONTRACT.md`: rules for the pet dog and the wild animals.
- `VEHICLE_CONTRACT.md`: rules for the 4x4 SUV (model, parts and behaviour).
- `BUDGETS.md`: limits for triangles and models so the game stays fast.
- `BUILD_SPEED.md`: how builds were made faster, and the commands to use.
- `PERFORMANCE.md`: frame-rate results for each speed round, newest first.
- `screenshots/`: pictures of the game used in the main README.
- `archive/`: old plans and finished reports, kept for history only.
