# Rust parity: open items only

Full audit (done rows too): docs/archive/RUST_PARITY_FULL.md. Godot reference repo: ../zombi servival.
Audited before R10 (2026-11-18). R10 (zombie behaviours, saves, data sounds) may have closed more rows: grep the code before making a task from a row.

- [missing] Player: Keyboard look (arrow keys turning camera) (`scripts/Player/KeyboardLook.cs`, `scripts/Player/CameraRig.cs`). Godot provides arrow-key camera panning; Rust input system (`game/src/input.rs`) only routes mouse delta.
- [missing] Player: Attached visual backpack mesh (`backpack_small.glb` / `backpack_large.glb` attached to chest bone) (`scripts/Player/PlayerBackpack.cs`). Godot renders visual backpack model attached to upper back bone; Rust player model currently has no backpack attachment.
- [missing] Combat: Gun recoil climb & muzzle flash (camera kick climb, muzzle flash light, first-person gun kick) (`scripts/Combat/GunEffects.cs`, `scripts/Combat/GunHandler.cs`). No muzzle flash sprite/light or recoil pitch climb implemented in renderer or camera.
- [logic only] Combat: AK-47 magazine swap submesh hide (hiding `mag` node during reload window) (`scripts/Combat/WeaponVisuals.cs:SetMagHidden`, `scripts/Combat/GunHandler.cs:MagHidden`). `mag_swap` timing intervals are parsed from `weapons.json`, but renderer cannot hide individual sub-mesh nodes.
- [missing] Combat: Expanded weapon arsenal (crossbow, hunting rifle, revolver, grenades, etc.) (GitHub #5) (None). **new (not in Godot)**. Owner requested expanded weapon arsenal on GitHub (#5); currently 9 weapons are implemented (5 melee, 5 firearms in `data/weapons.json`).
- [logic only] Zombies: Zombie scream behavior (sighting triggers scream, alerting nearby zombies via noise) (`scripts/Enemies/ZombieAI.Actions.cs:SpotPlayer`). Scream state logic exists in `game` crate, but `rotland/src/zombies.rs` does not handle scream outputs or emit noise events.
- [logic only] Zombies: Corpse eating behavior (zombie kneels and eats corpses or during idle) (`scripts/Enemies/ZombieAI.Actions.cs`, `scripts/Enemies/ZombieCorpses.cs`). Corpse eating logic exists, but `rotland/src/zombies.rs:213` passes `corpses: &[]` every frame.
- [logic only] Zombies: Crawler zombies from leg hits (hits below 0.6m break legs, shrink capsule, force crawl pose) (`scripts/Enemies/ZombieWounds.cs`, `scripts/Enemies/ZombieCrawl.cs`). Brain supports crawling state, but `rotland/src/zombies.rs:215` hardcodes `leg_hit: false`.
- [logic only] Zombies: Herd chase alert (chasing zombie alerts nearby idle/wander zombies within 8m) (`scripts/Enemies/ZombieHerd.cs`). Herd alert logic exists, but `rotland/src/zombies.rs:212` passes `nearby_zombies: &[]` every frame.
- [logic only] Zombies: Night horde shared wander target (night group wandering together) (`scripts/Enemies/ZombieHorde.cs`). `ZombieHorde` struct exists in `game` crate, but is never assigned to zombie brains in `rotland`.
- [logic only] Zombies: Banging on hideout doors/walls (banging when player is on ladder or roof) (`scripts/Enemies/ZombieHideouts.cs`). Hideout logic exists, but `rotland/src/zombies.rs:214` hardcodes `target_unreachable: false`.
- [logic only] Zombies: Safe zone protection (player in camp safe zone sealed off from zombie targeting) (`scripts/Enemies/ZombiePlayerLink.cs`, `scripts/Settlement/SettlementRegistry.cs:SealsOff`). `spawner` skips spawning inside camp safe zone, but `main.rs:1497` passes `self.player` to `zombies.update` even while player is inside camp.
- [missing] World: POI occlusion culling boxes (BoxOccluder3D for building walls and camp palisades) (`scripts/World/PoiOccluders.cs`). Custom engine relies on frustum culling on worker threads; box occluders are not implemented.
- [logic only] World: Unloaded chunk item persistence (saving dropped items across chunk unloads and sessions) (`scripts/World/WorldState.cs`, `scripts/World/DroppedItem.cs`). Dropped items persist in memory during active session via `WorldItems`, but are not serialized into save files.
- [logic only] Camp: Settlement safe zone tracking (`SettlementWatcher.cs` tracking visits, respawn camp selection) (`scripts/Settlement/SettlementWatcher.cs`). Struct exists in `game` crate, but `main.rs` never invokes it (respawn always uses camp index 0).
- [missing] Camp: Guild / faction system (reputation, guild hall, ranks, guild contracts) (GitHub #6) (None). **new (not in Godot)**. Owner requested guild/faction system on GitHub (#6); neither Godot nor Rust has guild mechanics.
- [logic only] Farming: Watering can refill at water (using water bottles in bag to refill empty watering can charges) (`scripts/Farming/FarmManager.cs:RefillCan`). Refill logic exists in `game` crate, but is not exposed or triggered in `rotland`.
- [logic only] Dogs: Shift+G Go Home command (sending dog back to camp safe zone) (`scripts/Dogs/DogManager.cs:GoHome`). Godot allows Shift+G to send the dog home to camp; `DogManager::go_home` and `DogMode::Home` exist in `game` crate, but `main.rs` only handles G key toggle stay.
- [logic only] Dogs: Dog naming dialog (popup to enter custom dog name on puppy purchase) (`scripts/Dogs/DogNameDialog.cs`). Naming popup UI and validation exist in `hub_ui`, but `main.rs:1349` immediately purchases puppy with default name "Rex" without opening dialog.
- [logic only] Vehicles: POI car spawning (35% chance to spawn hatchback at gas station & house_small POIs) (`scripts/Vehicles/CarSpawnRules.cs`, `scripts/Vehicles/CarManager.cs`). Only the starter camp car is spawned in `rotland`; POI car spawning at world buildings is not called.
- [missing] UI: New game difficulty selection screen (choosing preset, sliders for zombie amount/loot/damage/death) (`scripts/UI/DifficultyScreen.cs`). New Game button starts world immediately with default preset; difficulty setup screen before world start is missing.
- [logic only] UI: Profile character portrait (3D player avatar rendering / customizable portraits) (GitHub #8) (`scripts/UI/HubPortrait.cs`). **new (not in Godot)** feature requested on GitHub #8. Currently draws a 2D geometric silhouette placeholder instead of an interactive 3D model preview or selectable portrait.
- [missing] Audio: UI click sounds (playing `ui_click` on button clicks) (`scripts/Audio/UiClickSounds.cs`). egui button clicks are silent.
- [missing] Saves: Weapons equipped & magazine ammo persistence (`weapons` save system) (`scripts/Combat/WeaponHolder.cs`). Loaded magazine rounds and equipped weapon selection are not saved (start bat re-equipped on load).
- [logic only] Saves: Settlement visit state persistence (`settlements` save system saving visited camps & respawn camp) (`scripts/Settlement/SettlementWatcher.cs`). Logic exists in `game` crate, but `main.rs` never saves or loads the `settlements` system.
- [logic only] Settings: Graphics presets (Low, Medium, High controlling shadow blur, shadow distance, chunk load radius) (`scripts/Core/GraphicsPresets.cs`, `scripts/World/GraphicsApplier.cs`). Dropdown exists in settings menu, but presets are not applied to renderer shadow parameters or chunk streaming distance.
