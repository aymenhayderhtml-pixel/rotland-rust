# Art pipeline (.glb models)

## Style
Low-poly and flat-shaded. Color comes from a shared **palette texture**: one small image, and each face samples a color from it, so there are no big textures. This is cheap to render, and AI can generate it.

## Two sources
1. **Generated by AI with Blender scripts** (props, buildings, weapons, trees, rocks, crates, vehicles):
   - The worker writes `tools/blender/<name>.py`, which builds the mesh with `bpy` and exports `assets/models/<category>/<name>.glb`.
   - Run it with `blender -b --python tools/blender/<name>.py`.
   - Rules: Y-up export, real-world scale (1 unit = 1 m), origin at the bottom center, about 2000 triangles or fewer for props, apply transforms before export.
   - The script also renders a preview PNG to `assets/models/_previews/` so the owner can approve it.
2. **Animated characters** (player, zombies, animals, horse) are **also made by AI**. The owner decided no asset packs. Approach:
   - Blender script builds a **blocky low-poly body made of separate parts** (head, torso, upper/lower arms and legs) and a simple **armature** (skeleton). Each part is rigidly attached to one bone, so no complex skin weights are needed.
   - The script keyframes basic clips (`idle`, `walk`, `run`, `attack`, `die`) and exports them inside the `.glb`. Godot reads them through `AnimationPlayer`.
   - Godot adds **procedural animation** on top (code-driven): head look-at, leaning, foot IK on slopes and ragdoll on death. This hides the simple keyframes.
   - Zombies reuse the human skeleton with different proportions, clothes and "shamble" timing, so one rig serves many characters.
   - Expect a stylized, chunky look rather than realistic. That's the plan, not a bug.

## Review loop
The worker generates the model and preview, the orchestrator shows the preview to the owner, then the owner says OK or asks for changes.
